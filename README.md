# SALESLAND

Python application composed of independent services for data import and file export processes.

The project has been designed with a modular architecture, making it easy to maintain, extend and deploy in customer environments.

---

## Services

### Database Loader

Imports data from Microsoft Excel files into a PostgreSQL database.

Main responsibilities:

* Read and process Excel workbooks.
* Validate application and database configuration.
* Transform and map input data.
* Load processed data into PostgreSQL.
* Provide centralized logging with automatic log rotation.

### Export Service

Processes PDF and CSV files generated by the Kodak process.

Main responsibilities:

* Scan the Kodak output folder for PDF and CSV files.
* Match PDF and CSV files with the same base filename.
* Group files by month according to the CSV modification date.
* Assign consecutive numeric prefixes independently for each month.
* Move processed files to the corresponding SFTP output folder.
* Provide centralized logging with automatic log rotation.

## Installation

Clone the repository:

```bash
git clone https://github.com/borjaManuel/SALESLAND.git
cd SALESLAND
```

Install the project dependencies:

```bash
uv sync
```

---

## PostgreSQL with Docker

The project includes a Docker Compose configuration to run a PostgreSQL database for development and testing purposes.

Start the PostgreSQL container:

```bash
docker compose up -d
```

Check the container status:

```bash
docker compose ps
```

Stop the PostgreSQL container:

```bash
docker compose down
```

## Configuration

Each service has its own environment configuration, keeping service-specific settings isolated.

### Database Loader

Create the environment file from the provided template:

```bash
cp src/database_loader/.env.example src/database_loader/.env
```

Configure the database connection:

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=database
DB_USER=user
DB_PASSWORD=password
```

### Export Service

Create the environment file from the provided template:

```bash
cp src/export_service/.env.example src/export_service/.env
```

Configure the required paths:

```env
KODAK_OUTPUT_FOLDER=
SFTP_OUTPUT_FOLDER=
SFTP_ERROR_FOLDER=
```

The `.env` files contain environment-specific configuration and must not be committed to the repository.

## Logging

Both services provide centralized logging with automatic log rotation.

Logging configuration:

* Automatic file rotation.
* Maximum log size: **5 MB**.
* Maximum of **5** backup files.
* Console and file output.
